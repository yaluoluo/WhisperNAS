导入 NAS 文件

通过飞牛系统文件选择器选择 NAS 上的音视频文件，或选择一个目录进行递归导入。首次选择时，系统可能会提示授权应用访问所选路径。

所选文件或目录由飞牛系统授权后交给应用处理；不会上传或移动源文件，生成的 SRT 会保存到源文件旁边。目录选择按官方接口只支持单个目录。

模型参数说明

模型文件

使用你提供的 whisper.cpp 兼容模型，如 ggml-base-q8_0.bin、ggml-large-v3-turbo-q8_0.bin。量化类型、模型大小和精度取决于具体文件。

语言与字幕

当前固定使用中文识别（-l zh），输出 SRT 字幕（-osrt），并默认抑制非语音片段（--suppress-nst）。

设置

配置转写运行方式与硬件加速。更改仅影响新启动的任务。

推理设置

启用 Vulkan GPU 加速 关闭后将向 whisper-cli 传入 -ng，使用 CPU 推理。
对应 whisper.cpp 的 -dev / --device 参数，填写数字设备编号（例如 0、1）。留空时使用默认设备 0。
如果没有选择模型，任务会在开始前提示错误。
抑制非语音片段 使用 --suppress-nst 参数。

运行环境检查

Vulkan 加速需要 NAS 系统具备可用的 Vulkan 驱动与运行时。开关只控制 whisper.cpp 的参数，不会替系统安装驱动。

转写流程

  1. 系统 FFmpeg 提取音轨并转换为 16kHz、单声道、16-bit PCM WAV。
  2. 调用 whisper-cli -l zh -osrt --suppress-nst -m 模型 -f 音频.wav -of 输出路径 。
  3. 字幕以 SRT 格式保存在原视频/音频文件同目录；上传的文件则保存在应用数据目录。

W

Whisper NAS

面向飞牛 fnOS 的本地音视频字幕生成工具。

版本 0.1.5 Whisper.cpp 1.9.5 Vulkan / CPU

本地优先

音视频文件、模型和字幕均由 NAS 本地处理与保存。应用不会主动将媒体内容上传到第三方服务。

开源组件

语音识别由 Whisper.cpp 提供；音视频音轨提取使用系统 FFmpeg。请遵循各组件对应的许可证与使用条款。

使用提示

  • 首次使用前，请将兼容的 GGML 模型文件放入 models 目录并在设置中选择。
  • 模型越大通常需要更多内存与处理时间；长视频转写期间请留意 NAS 的资源占用。
  • Vulkan 设备能否使用取决于当前系统驱动、GPU 和 whisper.cpp 构建选项。
